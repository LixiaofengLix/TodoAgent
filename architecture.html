TodoAgent 架构总览

个人待办看板：添加任务，后台 Worker 自动领取并通过 Agent（cursor-agent CLI）执行。Python · FastAPI · SQLite · 原生前端。

悬停模块可高亮它的依赖与调用关系，点击查看职责、关键函数。整体是单进程：main.py 启动 uvicorn HTTP 服务，同时拉起 N 个守护线程作为 Worker，两者只通过 SQLite 交换状态。

任务有 5 种状态。点击下方按钮触发事件，观察状态流转（蓝色箭头为当前可用的转换）。

当前状态：

一次完整的「创建任务 → Worker 执行 → 用户追问 → 继续会话」流程。可逐步播放或自动播放。

CursorAgent 逐行解析 cursor-agent --output-format stream-json 的输出，转换为统一的 on_event(kind, data)，再由 Worker 落库。点击左侧事件类型查看映射路径。

两张表：tasks 与 messages（1:N）。字段定义集中在 db.COLUMNS，启动时自动给旧库补列。悬停字段查看说明。

worker.build_prompt() 根据「是否已有会话」和「未处理的用户消息」组合发给 Agent 的内容。调整左侧参数实时查看结果。
